# Картонный переполох — от первого лица

Откройте `Assets/Scenes/CardboardPlayground.unity` и нажмите **Play**. Нажмите в игровое окно, чтобы управлять взглядом мышью; **Escape** освобождает курсор.

Каждый сосед — один тонкий цельный картонный силуэт с нарисованными деталями, как у вырезанной вручную бумажной куклы. При ходьбе качается вся картонка влево-вправо. Отдельных подвижных рук, ног, головы и скелета нет.

| Управление | Действие |
| --- | --- |
| WASD / стрелки | Ходить |
| Мышь | Смотреть вокруг |
| Левый Shift | Ускориться |
| Пробел | Прыгнуть |
| E | Позвать соседей за собой |
| R | Устроить переполох на 10 секунд |
| Escape | Освободить курсор |
| F | Достать / убрать фломастер |
| ЛКМ в режиме фломастера | Коснуться NPC кончиком и рисовать с расстояния до 1,85 м |
| 1–5 | Чёрный, красный, синий, зелёный, фиолетовый фломастер |
| Колесо мыши | Толщина линии в режиме рисования |
| C | Очистить рисунок на NPC под курсором |

Соседи самостоятельно перемещаются по поляне, подпрыгивают при ходьбе, обходят друг друга и иногда отдыхают ровно 5 секунд. Покачивание цельной фигурки — до 13°. NPC поворачиваются по направлению движения, во время отдыха сохраняют поворот. Их можно обойти: видны лицо, тонкий картонный срез и отдельно нарисованная задняя сторона. Камера перспективная, на высоте глаз, без покачивания головы.

В режиме фломастера видна правая рука, держащая фломастер. Она следует за курсором по горизонтали и вертикали, фломастер наклоняется при движении мыши. Подойдите к NPC, наведите курсор и зажмите ЛКМ: кончик прижмётся к картонке в точке рисования. Фигурка замрёт в своей текущей позе, пока вы рисуете на ней. Обзор мышью на это время приостановлен.

У каждого NPC собственные рисунки, отдельно спереди и сзади; соседние фигурки с такой же внешностью не меняются. Рисунки остаются до выхода из Play Mode; C очищает обе стороны выбранного NPC. F возвращает управление взглядом, Escape освобождает курсор.

**Cardboard → Create playground** пересобирает сцену. **Save preview** сохраняет изображение камеры в `Screenshots/CardboardPreview.png`. **Verify movement and controls** запускает проверку сцены в игровом цикле Unity; отчёт — `Library/CardboardVerification.txt`.

Готовая фигурка: `Assets/Cardboard/Generated/CardboardRunner.prefab`. Все текстуры и геометрия создаются кодом и сохраняются в `Assets/Cardboard/Generated/CardboardArt.asset`. Рисунок силуэта — `CardboardCutout.cs`, простое покачивание — `CardboardRunner.Pose`, камера — `CardboardCamera.cs`.
