# НЕ СВОЙ — картонный завод

Unity 6000.6.2f1, URP. Основная сцена: `Assets/Scenes/FactoryShift.unity`.

Персонажи используют модели Human Lera и Human Nastya с исходными UV и текстурами из одноимённых папок `Game_Assets`. Материалы URP Lit: Base Map — авторская текстура, Base Color — белый, Metallic — 0, Smoothness — 0 (максимальная шероховатость), Cull Off — поверхности видны с обеих сторон. **Cardboard → Use imported people** обновляет персонажей в существующих сценах и prefab без пересборки окружения. Рисование фломастером работает по единому атласу, сохраняя независимые UV передней и задней сторон.

Игрок притворяется картонным рабочим. Нужно изготовить три детали по перфокартам, установить их в механизм и выйти. Подозрение, проверки рабочих, погоня и три финала сохранены.

## Новое рабочее место

Модели берутся из соседних папок `Assets/Game_Assets/Cardboard`. `Untitled.blend` — образец сборки. Станок использует Table, Conveer, Pipe, Krutilka, lever, Press, Under_Press, Shturval, три ёмкости Box и оригинальную анимацию Zabralo. Все три шестерёнки используют FBX и исходные текстуры из `gear wheel`, с готовыми UV, максимальной шероховатостью и двусторонним отображением. Панель насоса, кнопка решётки и принтер перфокарт пока собраны из простой геометрии.

1. В начале игры из принтера у рабочего стола автоматически выезжает заказ **1**. После установки первой детали выезжает **2**, затем **3**.
2. Нажмите **E** на рычаг подачи слева. Рука берётся за ручку и плавно тянет рычаг вниз; он возвращается обратно. Картон падает из трубы, затем едет по неподвижному конвейеру к центру стола. Толщина заготовки — 7 см, вдвое больше прежней.
3. **E** на левой крутилке Krutilka переключает тип **1 → 2 → 3**. Текущий номер показан над ней.
4. **E** на втором рычаге опускает пресс; рычаг также плавно движется с рукой и возвращается.
5. **E** на отдельной кнопке на столе слева от пресса поднимает защитную решётку с исходной анимацией.
6. Встаньте на жёлтую панель перед столом и прыгните **четыре раза**. Давление прибавляется при приземлении на панель; рядом с ней оно не растёт. Прыжки на включённом насосе не повышают подозрение.
7. Зажмите **ЛКМ** на штурвале и вращайте мышь по кругу **по часовой стрелке три оборота**. Рука следует за ободом, вращается только круглая дочерняя часть штурвала. Заготовка вращается под прессом. Полоска над штурвалом показывает резку. **E** на штурвале делает плавный небольшой поворот.
8. После резки решётка сама опускается. Поднимите пресс вторым рычагом и нажмите **E** на готовой детали под прессом.
9. Нажмите **E** на ванне с тем же номером, что на перфокарте. Деталь видимо опускается в жидкость. Неправильная ванна даёт неподходящую деталь.
10. Установите готовую деталь в нужный узел через **E**. После всех трёх ремонтов открывается выход.

Без давления станок не режет. Закрытый пресс блокирует выбор типа; закрытое забрало блокирует подъём пресса. Открытие забрала сбрасывает давление. Для снятия детали нужно открыть и пресс, и забрало. Незавершённая или неправильно обработанная деталь не устанавливается. **Q** выбрасывает ненужную деталь.

В цеху четыре рабочих места у верхней стены, место игрока — второе слева. Большой механизм находится снизу справа, пустая столовая соединена проходом снизу слева, выход — на правой стене. Коробки доставки убраны. Пресс и щит для финалов вынесены на отдельную площадку за пределами цеха.

## Управление

- **WASD / стрелки**, мышь — ходьба и обзор; **Shift** — бег; **Пробел** — прыжок.
- **E** — физические органы станка, перфокарты, детали, ванны, ремонт и выход.
- **ЛКМ** — нажать на орган станка; удерживать на штурвале и вращать мышь — резка.
- **C** — притвориться картонкой; во время проверки нужно замереть на две секунды.
- **F** — фломастер; **1–5** — цвет; колесо — толщина; **C** с фломастером — очистка.
- **Esc** — отпустить штурвал / освободить курсор.
- **Enter** после финала — новая игра.

Экранный HUD, меню, подсказки, надписи на стенах и шкаф смены маски удалены из основной сцены. Номера, перфокарты, прибор давления и полоска резки находятся в игровом мире.

## Сборка и проверки

- **Cardboard → Create factory shift** — пересобрать основную сцену.
- **Cardboard → Verify factory gameplay** — проверить новый цикл, блокировки, все три детали, ванны, ремонт и выход. Отчёт: `Library/FactoryVerification.txt`.
- Новые сгенерированные материалы: `Assets/Cardboard/Generated/FactoryWorkstationArt.asset`.
- `FactoryWorkstation.cs` — механика; `FactoryWorkstationBuilder.cs` — сборка моделей; `FactoryStationControl.cs` — органы управления.
- `FactoryGear.cs` и `FactoryPunchcard.cs` — типы деталей и физические перфокарты.
