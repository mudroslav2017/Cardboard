# Старый станок КР-3

`LegacyFactory.zip` содержит исходные скрипты игры и редактора, сгенерированные ассеты, FactoryShift.unity и README до замены рабочего места.

Исходные `FactoryWorkbench.cs`, `FactoryWorkbenchBuilder.cs` и `WorkbenchControl.cs` также сохранены в проекте и не используются новой сценой. Старый `FactoryArt.asset` не перезаписывается новой сборкой.

Перед первой пересборкой редактор сохраняет копию открытой старой сцены в `Assets/Scenes/LegacyFactoryShift.unity`, включая несохранённые изменения. Её можно открыть для просмотра старого рабочего места. Полное восстановление предыдущей версии: распаковать архив во временный каталог и вернуть нужные Scripts, Editor, Generated и сцену в исходные пути. Новые исходные модели из `Game_Assets` в архив не включены и при восстановлении остаются на месте.
