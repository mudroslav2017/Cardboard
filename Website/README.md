# Among Flat — лендинг

Статическая страница по макету Figma: https://www.figma.com/design/y5n4POks9ptFkB75DuhkNQ/Untitled?node-id=1-3

Для открытия дважды нажмите `start-site.cmd` — он запускает локальный сервер в фоне и открывает сайт в браузере. Повторный запуск использует уже работающий сервер.

Для 3D-вывески нужен HTTP-сервер: используйте `start-site.cmd`. Все изображения, модели, текстуры, библиотека Three.js и шрифт сохранены локально, подключение к Figma или CDN для просмотра не требуется.

Для локального HTTP-сервера при установленном Node.js: `npm start`, затем http://127.0.0.1:4173/.

Макет 1440 × 3186 масштабируется по ширине окна с сохранением композиции. Кнопки и навигация пока без действий. Блок видео сохранён как заглушка из макета.

Масштабирование использует `transform: scale()` внутри контейнера с пропорциями макета, без CSS `zoom`, чтобы избежать различий Safari в размерах текста. Веб-копия `troublemarker-web.otf` имеет согласованные hhea/OS/2-метрики для macOS и Windows; контуры букв не изменены. Повторная подготовка шрифта с проверкой контрольной суммы: `npm run build:font`. Исходный `troublemarker.otf` сохранён.

Файлы сайта находятся в `dist/`: `index.html`, `styles.css`, `layout.js`, `billboard.js`, `assets/`, `models/`, `vendor/`. Для публикации загрузите содержимое `dist/` в корень домена. Сборщик для запуска не нужен.

Вывеска и две цепи подготовлены из FBX в `Models_Site` с исходными текстурами. Скрипт `scripts/build-models.mjs` переводит геометрию в GLB, оптимизирует текстуры в WebP и копирует Three.js для автономной загрузки. Для повторной подготовки: `npm install`, затем `npm run build:models`. Наведение на вывеску запускает покачивание с затуханием; касание и клавиатура тоже поддерживаются. При отключённых анимациях в настройках устройства вывеска остаётся неподвижной. Без WebGL показывается исходная иллюстрация.

Подвес в `dist/suspension.js` сохраняет постоянный равномерный масштаб обеих цепей (1,75) и вывески (0,768 — на 20% меньше предыдущей). Вся конструкция вращается вперёд-назад вокруг линии двух неподвижных верхних креплений; перспективная камера показывает движение в глубину. Проверка сохранения пропорций, креплений и движения на исходной геометрии: `npm run check:suspension`.
